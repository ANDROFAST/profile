# Portafolio de Alex Céspedes Sánchez

Sitio estático listo para GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub. Para una página principal de usuario, usa el nombre `TU_USUARIO.github.io`.
2. Sube el contenido de esta carpeta al repositorio.
3. En GitHub, entra a `Settings > Pages`.
4. En `Build and deployment`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda los cambios y espera a que GitHub genere la URL pública.

## Publicar sobre el repositorio actual

Este portafolio puede reemplazar la web antigua del repositorio público `ANDROFAST/profile`.
Antes de subirlo, conviene revisar visualmente la versión final y luego copiar únicamente los
archivos de esta carpeta al repositorio.

## Archivos principales

- `index.html`: contenido del portafolio.
- `style.css`: estilos responsive.
- `script.js`: menú móvil y resaltado de navegación.
- `assets/`: imágenes generadas para proyectos del portafolio.
- `.nojekyll`: evita el procesamiento Jekyll innecesario.
- `CV_Alex_Cespedes_Sanchez.pdf`: CV descargable.
